# Orange poster

Subject: Łukasz Budziak's notes on software engineering and cybersecurity. Readers are developers and CTF participants; the landing page's job is to bring them into the author's actual writeups.

Palette: signal orange #FF681F, midnight navy #14213D, paper #F7F8FA, chalk #FFFFFF, muted blue #64718A.

Typography: Source Sans 3 at weight 900 with a compressed display treatment for the poster headline; Source Sans 3 at 400–600 for reading; Fira Code for dates, metadata, and code. Both fonts ship with the existing project.

Layout: a navy masthead sits above a generous orange typographic poster. A quiet paper writing section and a navy author section follow. Article pages keep the orange title panel but switch to paper and a narrow reading column.

```
[ EloToJa                        Writing  About  GitHub ]
[ NOTES ON SOFTWARE & SECURITY                        ]
[ BREAK                  { inspect                     ]
[ IT DOWN.                 understand                  ]
[ explanatory line         build }                     ]
[ Read the latest writeup ↗                            ]
[ WRITING            real featured article             ]
[ ABOUT              Łukasz Budziak                    ]
```

Signature: a huge, compressed two-line headline paired with a code-brace composition; the visual is a poster about inspecting and understanding software, grounded in the article's observation-before-exploitation theme.

Critique before implementation: an orange hero with giant generic motivational copy risks becoming a creative-agency page. Keep the subject label explicit, use the real article and author biography, and make the bracket annotation describe the working method. Omit ornamental numbering, invented posts, fabricated statistics, and animation. Article typography returns to natural proportions for reading. Mobile stacks the composition with no horizontal clipping; keyboard focus remains visible.
