# Glass workspace

Subject: Łukasz Budziak's software engineering and cybersecurity writing. Audience: programmers and CTF participants. Job: make the real Cyber Apocalypse writeup easy to discover and read.

Palette: mist #e9eff7, glass #f7faff, ink #172e50, slate #536780, electric #175de8, ice #cddcf3.
Typography: Fira Code Variable for the restrained identity, labels and code; Source Sans 3 Variable for large tightly set display text and highly readable prose. Both are local dependencies; no font network calls.
Layout: an architectural window of translucent panels, with a narrow author rail beside a generous writing desk. A single genuine article occupies the large feature pane instead of invented posts.


Signature: a blue glass window whose intersecting panes label the actual disciplines in the author's work. It suggests a workspace rather than a fake desktop interface.

Critique before build: avoid stock glassmorphism's floating bubbles and glowing gradients. Use a crisp blue-gray architectural background and one purposeful window composition. Replace decorative traffic-light controls with actual author/topic labels. Keep translucency away from long-form text to preserve contrast. Article includes the complete source, generated heading navigation, narrow reading measure, and mobile TOC.
